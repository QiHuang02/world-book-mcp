# 写作规则

写完 source 后按本清单检查和修订。

## 禁词与八股化

检查：

- 一丝、一缕、一抹
- 不易察觉、难以察觉
- 鲜明对比、形成对比
- 弧度、弯起嘴角、翘起嘴角
- 喉结、指节发白
- 不是……是…… / 没有……而是……
- 似乎、几乎、仿佛、如同、宛如、好像
- 石子、湖面、涟漪、拉满的弓、琴弦、闪电、晨光、星辰

## 白描

- 写角色做了什么，不解释为什么。
- 写角色说了什么，不标注“用什么语气”。
- 写场景真实存在的东西，不写不存在的意象。

## 具体性

- 性格不贴标签，写行为。
- 外貌不写美感，写特征。
- 能力写限制、代价、条件。
- 关系写可见互动。

## user 边界

禁止预设：

- {{user}} 的性别、外貌、身体
- {{user}} 的行动
- {{user}} 的心理和认知

## 第四面墙

角色不应知道：AI、模型、提示词、创作者、玩家知道剧情等。

## 处理方式

发现问题后，直接修改 source 内容，再调用 `write_source_file overwrite=true` 落盘。
