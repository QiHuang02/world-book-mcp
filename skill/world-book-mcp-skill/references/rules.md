# 写作规则：中文 YAML、白描、绝对零度、反八股

写完 source 后按本清单检查和修订。规则适用于世界观、角色、NPC、开场白、MVU 文本规则、EJS 阶段内容等创作正文。

## 输出结构

创作内容优先使用中文 YAML 结构：

```yaml
模块名称:
  子项:
    - 具体事实
    - 具体行为
```

要求：

- 2 空格缩进。
- 键名使用中文或稳定英文标识，不混乱切换。
- 世界书条目推荐 XML-wrapped YAML：`<角色名_idN> ... </角色名_idN>` 或语义标签。
- draft YAML 仍以工具 schema 为准，不为了中文化破坏字段名。
- 输出成品内容时不写“这是角色卡/世界书/AI/模型/提示词”。

## 绝对零度

绝对零度是事实写作，不是冷淡文风。

- 写可观察事实，不写叙述者评价。
- 写角色做了什么，不替角色解释“本质上/其实/内心深处”。
- 写角色说了什么，不标注“用什么语气”。
- 写场景真实存在的东西，不写不存在的意象。
- 写因果链：条件 → 行动 → 后果，不用空洞升华结尾。

可用：

```yaml
行为:
  - 她把校服领带塞进书包，进校门前再取出来系上。
  - 排练结束后，她会把断掉的琴弦收进铁盒。
```

避免：

```yaml
行为:
  - 她像困兽一样压抑着灵魂深处的叛逆。
```

## 白描

- 外貌写特征，不写美感。
- 性格写行为，不贴标签。
- 关系写互动，不写抽象评价。
- 能力写条件、效果、限制、代价。
- 情绪写动作和话，不写大段心理解释。

## 反八股清单

发现以下写法，优先删除或改成具体事实：

### 模糊词

- 似乎、几乎、仿佛、如同、宛如、好像
- 不易察觉、难以察觉
- 某种、一些、无数、复杂、神秘、宏大、古老、强盛、繁华

### 廉价比喻 / 意象

- 像小兽、像小兔子、投石入湖、心湖泛起涟漪
- 拉满的弓、琴弦、闪电、晨光、星辰、月光流淌
- 一丝、一缕、一抹

### 微表情和模板动作

- 嘴角上扬、嘴角勾起、弧度
- 眼里闪过光、指尖泛白、喉结滚动
- 身体微微一僵、肩膀微不可察地颤抖

### 语气描写

- 用温柔的语气说
- 带着不容置疑的口吻
- 声音里带着复杂情绪

改法：只保留台词，或写对方能听见的声量、停顿、句长。

### 否定转折句

- 不是……而是……
- 没有……只是……
- 表面……实际上……

改法：拆成两个事实，不用句式替代内容。

### 空洞升华

- 这一刻命运的齿轮开始转动。
- 一切都将不同。
- 两人的故事由此展开。

改法：以可互动动作、未完成事件或角色等待回应收尾。

## 语料纯净度

角色台词示例、三面性语料、NPC 参考语料必须是纯台词：

```yaml
参考语料:
  - "{{user}}，这张表十分钟后交。"
  - "别站在门口，进来。"
```

不要混入动作、表情、心理：

```yaml
参考语料:
  - 她皱眉看着{{user}}，用严厉的语气说："进来。"
```

## user 边界

禁止预设：

- `{{user}}` 的性别、外貌、身体。
- `{{user}}` 的行动、姿势、表情。
- `{{user}}` 的心理、认知、记忆、选择。
- 未确认的身份、关系、社会地位。

允许：

- 角色对 `{{user}}` 的称呼和态度。
- 场景给 `{{user}}` 留出的空间。
- 角色等待、邀请、询问、递出物品。

## 第四面墙

角色不应知道：

- AI、模型、提示词、token、世界书、角色卡。
- 创作者正在写设定。
- 玩家知道剧情、用户正在测试卡。

## 处理方式

发现问题后，直接修改 source 内容，再调用 `write_source_file overwrite=true` 落盘。最终生成前至少检查：

- [ ] 没有万能美人描写。
- [ ] 没有用标签代替行为。
- [ ] 没有复述模型已知常识。
- [ ] 没有预设 `{{user}}`。
- [ ] 没有第四面墙污染。
- [ ] 台词示例都是纯台词。
- [ ] 开场白以可互动场景收尾。
