# 材料转化

## 分流

- 结构化材料：直接拆角色、世界、物品、事件。
- 叙事材料：先建章节索引和重要事件，再提取角色维度。
- 混合材料：标记哪些是来源事实，哪些是原创补足。

## 原则

- 原文没有的不补。
- 不把长原文塞进 MCP。
- 只把整理后的事实、sourceRefs、planned entries 写入 plan/draft。
- 编写条目前先复述来源事实，避免幻觉。

## 二创 outline

使用 extraction/derivative outline 工具记录：章节索引、角色维度、世界维度、重要事件、 planned entries。

## 散文转数据库

把文学段落改成可查询字段：身份、外貌特征、关系证据、关键事件、限制、触发词。删除抒情和作者解释。
