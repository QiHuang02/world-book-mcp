# 内容规则

## 数据库式 YAML

世界书条目优先使用 XML 包裹 YAML，短字段、短句、具体事实。避免整段散文塞进条目。

## 外貌

只写可辨识特征：发色、发型、衣物磨损、姿态、标志物、习惯动作。避免“精致、白皙、漂亮、帅气、完美”等万能美人词。

## 背景与关系

背景只写关键事件和后果。关系写具体画面、债务、承诺、误会、边界，不写“感情深厚”“关系很好”。

## 禁词与八股化

避免：一丝、一缕、一抹、弧度、嘴角微微上扬、眼中闪过一丝、似乎、仿佛、宛如、好像、解释性破折号。

## 具体性

禁止“某城市、某组织、某学校、待定、TODO、占位”。未知内容应成为 pending decision。

## 第四面墙

成品条目不得出现“角色卡、世界书、AI、模型、玩家正在使用、prompt”等工具层表述。

默认使用简体中文。
