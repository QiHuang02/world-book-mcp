# 二次解释方法论

二次解释是作者对角色的终极注释。它不是让 AI 觉得角色应该怎么演，而是告诉 AI"我的角色是这样的，不是你想的那样"。它防止 AI 用自己数据库里的理解去补全角色。

## 一、什么时候需要二次解释

- 角色有表里矛盾（表面冷漠实则护短）
- 角色的某个性格容易被 AI 误解（"大大咧咧"不等于"粗心大意"）
- 角色在不同场景下行为差异大，需要解释内在一致性
- 角色有复杂的情感逻辑，单靠性格条目 AI 会简化处理

**不需要二次解释的情况**：角色性格简单直接，性格条目已经足够清晰。

## 二、二次解释 vs 演绎指导

| | 二次解释 | 演绎指导 |
|---|---|---|
| 本质 | 作者告诉 AI 角色真正是什么样 | AI 觉得角色应该怎么演 |
| 效果 | 角色保持作者的创作意图 | AI 把角色变成 AI 的理解 |
| 内容 | "她的大大咧咧不是粗心，是不愿意纠结" | "请表现得大大咧咧" |

## 三、每条二次解释的结构

围绕一个性格点展开，告诉 AI：

1. **这个性格真正的含义是什么**
2. **它不是什么**（防止 AI 误解）
3. **什么时候出现，什么时候不出现**
4. **和其他性格之间的关系**

## 四、格式

```yaml
<rephrase>
对角色的理解与思考:

  关于[性格点/行为模式]: |
    [具体解释内容]

  关于[另一个性格点]: |
    [具体解释内容]

  总结_性格调色盘: |
    这就是[角色名]的性格调色盘，在这个调色盘上有着无数的颜色，
    任何时候都是由多种性格、行为、回忆组合驱动着[角色名]，
    并非单纯的一种颜色、一个标签。
</rephrase>
```

## 五、示例

```text
关于大大咧咧的本质: |
  大大咧咧指的是她不愿意多想，不愿意去纠结，不愿意浪费时间做无意义的事，
  而非指她粗心大意什么也不在意。相反，大大咧咧的表象下藏着她的细腻与温柔，
  比如她在帮助女生的时候，她在女生间有"王子"的称号。

关于乐观的双重性: |
  她的乐观在于和{{user}}在一起时是真实自然的，而非全都是虚假的。
  但和非{{user}}的人相处时，乐观就是实打实的假象，是维持人设用的。
  理由是：如果别人担心会让在外的父母担心，也会让{{user}}为自己担心。

关于乏力状态的机制: |
  乏力并非常态，大多是在{{user}}陪伴较少的时候才可能发生。
  她不会无缘无故陷入内耗。哪怕陷入这种状态后恢复得也很快，
  通过回忆、与{{user}}聊天、看{{user}}照片迅速调整自己。
  她允许自己偶尔的"乏力"，但不会让自己长时间陷入这种状态。
```

## 六、核心约束

- **必须由用户自己写**。AI 写的二次解释只会重复数据库理解，失去纠正意义
- 用户不知道怎么写时，**用问题引导思考**，不直接替写
- 不通顺、重复的内容**不要改**——这是作者对角色最真实的理解
- 只写"怎么运作"，不写"为什么"（"为什么"是二次解释本身的活）
- 不出现"因为""本质上""其实""内心"等解释性词汇

## 七、条目配置

```text
position: after_char（紧跟性格条目之后）
order: 性格条目 order + 1
constant: 与性格条目一致（单卡蓝灯，多卡绿灯）
keys: 与性格条目相同
preventRecursion: true
excludeRecursion: true
```

## 八、MCP 工作流

```text
→ 引导用户思考角色的深层逻辑
→ 用户提供二次解释文本
→ create_draft_slice(worldbook_entry, id="char-rephrase")
→ update_draft_fields(content=用户文本, entryType="other", position="after_char", order=性格order+1)
→ validate_draft(scope="worldbook")
```

## 九、引导用户的问题模板

当用户不知道怎么写二次解释时，可以用以下问题引导：

- "她的[性格点]在什么情况下会出现？什么情况下不会？"
- "AI 可能会把她的[行为]理解成[错误理解]，你觉得真正的原因是什么？"
- "她在[场景A]和[场景B]表现完全不同，这两面之间的关系是什么？"
- "如果 AI 把她演成了[某种刻板印象]，你会觉得哪里不对？"
- "她的[性格A]和[性格B]看起来矛盾，它们是怎么共存的？"

## 十、自查清单

- 每条二次解释是否围绕一个性格点展开？
- 是否说明了"真正含义""不是什么""何时出现/不出现""与其他性格的关系"？
- 是否没有通用演绎指导（"应该怎么演"）？
- 是否保留了用户原文，没有润色修改？
- 是否没有出现"因为""本质上""其实""内心"？
