# 二创信息提取方法论

本文指导如何从已有作品（小说、游戏、影视、wiki）中系统性提取信息并转化为世界书/角色卡。适用于用户提供源材料或要求网络搜索的场景。

> 边界：二创提取模板、角色维度判断、禁词剔除和世界观取舍均由 skill 执行。MCP 不再注册 derivative extraction 专用工具；最终结果通过 `update_plan` 与 `entry` slices 落地。

## 一、材料分流

收到来源材料后先判定类型：

- **结构化材料**：直接拆角色、世界、物品、事件。
- **叙事材料**：先建章节索引和重要事件，再提取角色维度。
- **混合材料**：标记哪些是来源事实，哪些是原创补足。

核心原则：原文没有的不补；不把长原文塞进 MCP；编写条目前先复述来源事实，避免幻觉。

## 二、信息来源判断

| 来源 | 处理方式 |
|------|---------|
| 用户提供文本文件 | 直接读取，标注行号，进入提取流程 |
| 用户要求网络搜索 | 搜索后整理为结构化摘要，再进入提取流程 |
| 用户口述 | 记录为 plan 中的事实陈述，标注“用户口述” |

**MCP 对接**：

```text
init_project(scan_existing=true)
→ update_plan：记录素材来源、任务类型、输出目标、sourceRefs 与提取维度
→ 按本文件整理提取表
→ create_draft_slice(draft_type="entry") 后使用 update_entry_content / update_entry_config 写入条目
```

## 三、网络搜索结果处理

搜索得到的信息写成简短摘要，每条 50-100 字，标注来源：

```text
## 角色A
- 身份：XX学院三年级生，风系魔法师（来源：百科页面）
- 外貌：银灰色短发，左眼有竖贯眉眼的疤痕（来源：wiki人物页）
- 关键事件：在XX战役中失去左臂，后获得义肢（来源：剧情分析帖）

## 世界观
- XX大陆：由四个国家组成的奇幻世界，以魔力为能源（来源：设定集摘要）
```

## 四、原文标注与章节索引

对文本文件执行：

1. **章节行号索引**：

```text
第1章: L1 - L350
第2章: L351 - L720
```

2. **首轮通读标注**：

| 标记 | 含义 |
|------|------|
| `[W]` | 世界观信息 |
| `[C]` | 角色信息 |
| `[I]` | 物品/能力 |
| `[★]` | 重要章节 |

3. **角色出场标定**：

```text
- 角色A：一句话形象。出场：第1/3/5/7章
- 角色B：一句话形象。出场：第2/4/6章
```

## 五、角色提取维度

对每个核心角色按以下维度逐项提取。每个维度输出格式：

```text
### [维度名称]
- 手法总结：源材料在此维度的表现手法
- 原始例句：1-3段原文引用，标注章节行号
- 禁词标记：原文中的比喻/禁词，标注改写方案
- 提取结果：剔除禁词后的白描内容
```

### 维度清单

| 维度 | 提取内容 | 注意事项 |
|------|---------|---------|
| 基本信息与首次出场 | 姓名、年龄、性别、身份、首次出场章节 | 原文没写的不估测 |
| 外貌特征 | 只提取偏离 AI 默认认知的差异特征 | 遮住名字能认出是谁 |
| 身份定位 | 职业、社会角色、与 user 的关系 | 一句话，不展开 |
| 性格线索 | 从行为中提取，不提取作者贴的标签 | 每条附带行为依据 |
| 关键事件 | 只提取“改变了角色”的转折事件 | 删除流水账 |
| 关系网络 | 认识方式、互动模式、关系动态 | 写具体画面 |
| 能力与物品 | 获得方式、具体效果、限制代价 | 不写“威力强大” |
| 出场章节总览 | 该角色出现的所有章节 | 标注每章角色相关内容 |

### 禁词剔除规则

| 类别 | 剔除内容 | 转化方式 |
|------|---------|---------|
| 意象比喻 | “眸如星辰”“晨光般暖白” | 转为特征白描：“天青色瞳” |
| 万能修饰 | “精致的”“白皙的”“好看的” | 直接删除 |
| 默认特征 | 中国人黑发黑眼、18岁年轻 | 删除 |
| 性格标签 | “温柔”“善良”“强大” | 转为原文行为依据 |
| 主观评价 | “强大的”“神秘的” | 删除 |
| 语气修饰 | “带着温柔的口吻” | 只保留对话内容 |

详细禁词库见 `content-rules.md`。

### 不确定信息处理

- 原文没写 → 标记 `// 原文未提及`，不补全
- 信息不足 → 只提取已有信息，不推断
- 前后矛盾 → 以首次出场为准，标注变化

## 六、世界观提取

先判定类型（A/B/C，参见 `worldbuilding-methodology.md`），再按维度提取：

- **地理**：区域划分、关键地点（去掉风景抒情）
- **历史**：影响当前格局的关键事件（去掉编年史）
- **势力**：名称 + 定位 + 诉求 + 关系
- **规则**：力量来源/等级/运行逻辑/自造词定义
- **社会**：阶层/文化/禁忌

**去小说化**：

| 原文写法 | 提取写法 |
|---------|---------|
| “在这片广袤无垠的大地上” | 删除 |
| “六大仙宗是最负盛名的门派” | 六大仙宗：剑宗、丹宗... |
| “充满机遇与挑战的世界” | 删除 |

## 七、MCP 工作流

```text
init_project
→ update_plan：记录素材来源、任务类型、输出目标、sourceRefs、章节行号索引
→ 阅读源材料，按本文件维度提取
→ update_plan：写入提取摘要、planned entries、原创补写边界
→ create_draft_slice(draft_type="entry") 逐条创建世界书条目
→ 使用 update_entry_content / update_entry_config 填写条目正文与配置
→ 如需角色卡：update_character_profile + update_character_greetings
→ validate_project(scope="all")
→ 按 content-rules.md 做禁词/八股/具体性自查
→ generate_json
```

## 八、常见错误

| 错误 | 正确 |
|------|------|
| 搬运原文比喻（“双眸如星辰般灿烂”） | 剔除比喻，提取特征（“天青色瞳”） |
| 性格写成标签（“善良”） | 写具体行为（“看见摔倒的小孩会停下扶起”） |
| 关系写成抽象形容（“关系很好”） | 写具体画面（“每周五一起去旧书店”） |
| 补全原文没有的信息 | 标记 `// 原文未提及` |
| 世界观保留小说叙述 | 转为数据陈述 |
| 凭记忆写条目不复读原文 | 按依赖章节复读后再写 |

## 九、自查清单

- 所有外貌提取是否只含差异特征？
- 意象比喻是否已转化为白描？
- 性格是否均有原文行为依据？
- 关系是否为具体互动画面？
- 关键事件是否只提取了转折性事件？
- 世界观是否去除了小说叙述？
- 原文没写的是否标记了“原文未提及”？
- 每个维度是否附带原始例句和章节出处？
